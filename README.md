
# Book Inventory

Basic CRUD Operation to handle a Book Inventory.

## Environment Variables for client

To run client, you will need to add the following environment variables to your .env file

`BASE_URL` - BACKEND URL

For our task, server is running at 9000 port



## Environment Variables for server

To run server, you will need to add the following environment variables to your .env file

`JWTSECRET`

`MONGO_URI`


## Features

- CRUD Operations for Book Inventory
- Statistics
- Secure API's with Cookie
- Authenticated using JWT
